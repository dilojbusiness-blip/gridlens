Demo limits & comparison rules
Limits per input
File size1 MiB
Rows10,000
Columns100
Cells100,000

Keys must be unique and nonblank. Values are compared as literal strings; numeric tolerance is not implemented. Header mode matches exact column names. Up to 100 difference samples are shown, with exact total counts. The extension has higher CSV limits and separate XLSX limits.

GridLens

Local by design. Literal by default.

Data & privacy

Comparison runs locally in a Web Worker. Nothing is uploaded, sent to a server, or tracked.

There is no application input storage. Use Clear data before leaving; browser session/form restoration is outside our control.

Limitations

Sample-size demo only; duplicate keys are reported, not auto-fixed. Use the extension for full limits.
