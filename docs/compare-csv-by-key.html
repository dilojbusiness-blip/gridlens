Compare CSV files by key

Paste two CSVs, pick a key column for each, and compare records regardless of row order. Runs entirely in this browser tab using a Web Worker.

Don't paste sensitive data on a shared computer. Pasted text stays in this browser tab's memory; it is not persisted or uploaded, and there is no tracking.

Demo limits

The full VS Code extension supports 50 MiB per file, up to 100,001 rows, 512 columns and 1,000,000 cells. Install it for larger files.

Data & privacy

Comparison runs locally in a Web Worker. Nothing is uploaded, sent to a server, or tracked.

There is no application input storage. Use Clear data before leaving; browser session/form restoration is outside our control.

Limitations

Sample-size demo only; duplicate keys are reported, not auto-fixed. Use the extension for full limits.
